# Canon Update — Aetheric Channels → Aetheric Threads (June 2026)

## The change
The magic **resource** is renamed **Aetheric Channels → Aetheric Threads** (casual: **"Threads"**).
Spell-slot equivalent, still tiered 1st–9th, still spent to Weave a Working and restored on Deep
Attunement. Nothing mechanical changes — it is a term + flavor swap that completes the weave
metaphor (Loom · Weave · Workings · Fate-threads).

**Flavor:** *Every Working is woven from Aetheric Threads — strands of raw possibility drawn from
the Aether and gathered into a single pattern.*

## Rules that travel with it
- **Verb retired:** "channel / channeling" is now fully banned (it was the original Wheel-of-Time
  overlap). Use **weave** or **draw**. (e.g. "may channel their sign's force" → "may weave…";
  "the four channel into one" → "the four weave into one".)
- **"Chaos Channeler"** tradition (Wild Surge Master) → **"Chaos-Weaver."**
- **"Orisha Channel"** feature (Ashé-Touched) → **"Orisha Conduit"**, and "Community Root Channel
  restore" → "Community Root restore." (Ashé-Touched draw on the **Ashé Vessel**, not Threads, so
  they must not read as Thread-users.)
- **Glossary equivalence row:** "Aetheric Thread = Spell slot."

## Intentional collision (by design)
"**thread**" now denotes **both** the magic resource **and** Fate/Bond threads. This is deliberate:
magic and Fate are the same Loom. Context disambiguates; no separate word is used.
